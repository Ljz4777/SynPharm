### 2.2 步骤1：安装基础依赖

#### Windows环境

**JDK 21安装**：
```powershell
# 下载JDK 21
# https://adoptium.net/temurin/releases/?version=21

# 验证安装
java -version
# 输出: openjdk version "21.0.x"

# 设置环境变量（PowerShell）
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-21.x.x-hotspot"
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
```

**Maven安装**：
```powershell
# 下载Maven
# https://maven.apache.org/download.cgi

# 验证安装
mvn -version
# 输出: Apache Maven 3.9.x
```

**Python 3.10+安装**：
```powershell
# 下载Python
# https://www.python.org/downloads/

# 验证安装
python --version
# 输出: Python 3.10.x 或更高
```

**MySQL安装**：
```powershell
# 方式1：下载MySQL Installer
# https://dev.mysql.com/downloads/installer/

# 方式2：使用Docker（推荐）
docker run -d --name mysql-synpharm `
  -p 3306:3306 `
  -e MYSQL_ROOT_PASSWORD=root123 `
  -e MYSQL_DATABASE=synpharm `
  -e MYSQL_USER=synpharm `
  -e MYSQL_PASSWORD=synpharm_pass `
  mysql:8.0

# 验证
docker exec -it mysql-synpharm mysql -u synpharm -psynpharm_pass -e "SELECT 1"
```

**Redis安装**：
```powershell
# 方式1：使用Memurai（Windows版Redis）
# https://www.memurai.com/

# 方式2：使用Docker（推荐）
docker run -d --name redis-synpharm `
  -p 6379:6379 `
  redis:7-alpine

# 验证
docker exec -it redis-synpharm redis-cli ping
# 输出: PONG
```

### 2.3 步骤2：启动基础服务并初始化数据库

```powershell

docker start mysql-synpharm

# 启动Redis（如果使用Docker）
docker start redis-synpharm

# 验证服务状态
docker ps
# 确认两个容器都在运行
```

**创建数据库和表**：
```powershell
# 如果数据库还没创建
docker exec -it mysql-synpharm mysql -u root -proot123 `
  -e "CREATE DATABASE IF NOT EXISTS synpharm DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

docker exec -it mysql-synpharm mysql -u root -proot123 `
  -e "CREATE USER IF NOT EXISTS 'synpharm'@'%' IDENTIFIED BY 'synpharm_pass';"

docker exec -it mysql-synpharm mysql -u root -proot123 `
  -e "GRANT ALL PRIVILEGES ON synpharm.* TO 'synpharm'@'%'; FLUSH PRIVILEGES;"
```

### 2.4 步骤3：启动FastAPI服务

### 2.8 常见启动问题排查

| 问题 | 原因 | 解决方案 |
|:---|:---|:---|
| 端口8080被占用 | 其他服务占用 | `netstat -ano \| findstr :8080` 找到PID后结束进程 |
| 端口8000被占用 | 其他服务占用 | `netstat -ano \| findstr :8000` 找到PID后结束进程 |
| MySQL连接失败 | 服务未启动或配置错误 | 检查MySQL是否启动，确认用户名密码正确 |
| Redis连接失败 | 服务未启动 | 检查Redis是否启动，确认端口6379 |
| FastAPI依赖安装失败 | 网络问题 | 使用国内镜像源：`pip install -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| Maven编译失败 | 依赖下载慢 | 配置Maven国内镜像（阿里云） |
| 前端启动失败 | node_modules损坏 | 删除node_modules重新安装：`rm -rf node_modules && npm install` |

### 3.10 常见Docker问题排查

| 问题 | 原因 | 解决方案 |
|:---|:---|:---|
| Docker未运行 | Docker Desktop未启动 | 启动Docker Desktop |
| 端口被占用 | 其他服务使用了端口 | 停止占用服务或修改docker-compose端口映射 |
| 数据库连接失败 | MySQL未就绪 | 等待健康检查通过：`docker-compose ps` |
| 构建失败 | 网络问题或依赖缺失 | 检查网络，确保Docker Hub可访问 |
| 服务启动慢 | 首次构建需要下载镜像 | 耐心等待，国内用户可配置镜像加速 |
| 日志显示连接拒绝 | 服务启动顺序问题 | 使用`depends_on`的`service_healthy`条件 |

## 4. GPU服务器部署

### 4.1 前置要求

1. 安装 NVIDIA GPU 驱动
2. 安装 NVIDIA Docker

```bash
# 检查GPU状态
nvidia-smi

# 检查NVIDIA Docker
docker run --rm --gpus all nvidia/cuda:11.8.0-base-ubuntu22.04 nvidia-smi
```

### 4.2 修改 FastAPI Dockerfile（GPU版）

创建 `Dockerfile.gpu`:

```dockerfile
FROM nvidia/cuda:11.8.0-cudnn8-runtime-ubuntu22.04

WORKDIR /app

RUN apt-get update && apt-get install -y \
    python3.10 \
    python3-pip \
    && rm -rf /var/lib/apt/lists/*

COPY requirements.txt .
RUN pip3 install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### 4.3 修改 docker-compose.yml

```yaml
fastapi:
    build:
      context: ./synpharm-fastapi
      dockerfile: Dockerfile.gpu
    container_name: synpharm-fastapi
    ports:
      - "8000:8000"
    environment:
      DEVICE: cuda:0
      BATCH_SIZE: 50
    volumes:
      - ./synpharm-fastapi/models:/app/models
      - ./synpharm-fastapi/logs:/app/logs
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: 1
              capabilities: [gpu]
    networks:
      - synpharm-network
```

### 4.4 启动GPU服务

```bash
docker-compose up -d fastapi

# 验证GPU是否可用
docker-compose exec fastapi python -c "import torch; print('GPU available:', torch.cuda.is_available())"
```

## 7. 常见问题

### Q1: MySQL连接失败

确保MySQL服务已启动，并且允许远程访问:

```sql
ALTER USER 'synpharm'@'%' IDENTIFIED WITH mysql_native_password BY 'synpharm_pass';
FLUSH PRIVILEGES;
```

### Q2: Redis连接失败

检查Redis是否绑定到正确的地址:

```bash
# 修改redis.conf
bind 0.0.0.0
protected-mode no
```

### Q3: FastAPI无法识别GPU

确保已安装NVIDIA Docker，并且容器已正确配置GPU资源。

### Q4: 前端请求跨域

开发环境下，Vite已配置代理。生产环境通过Nginx反向代理解决。

### Q5: API Key认证失败

在FastAPI的 `.env` 文件中配置 `API_KEYS`，或留空禁用认证:

```bash
API_KEYS=[]
```
