## 2. 本地开发测试

### 2.1 后端服务

```bash
# 进入后端目录
cd synpharm-backend

# 编译项目
mvn clean package -DskipTests

# 运行（确保MySQL和Redis已启动）
java -jar target/synpharm-backend-1.0.0.jar
```

服务启动后访问: `http://localhost:8080`

### 2.2 FastAPI服务

```bash
# 进入FastAPI目录
cd synpharm-fastapi

# 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

# 安装依赖
pip install -r requirements.txt

# 启动服务
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

服务启动后访问: `http://localhost:8000/docs`

### 2.3 前端服务

```bash
# 进入前端目录
cd synpharm-frontend

# 安装依赖
npm install

# 开发模式运行
npm run dev
```

服务启动后访问: `http://localhost:5174`

## 3. Docker Compose 一键部署

### 3.1 全栈部署（CPU模式）

```bash
# 进入项目根目录
cd SynPharm

# 构建并启动所有服务
docker-compose up -d

# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down

# 停止并删除数据卷
docker-compose down -v
```

### 3.2 服务端口映射

| 服务 | 端口 | 说明 |
|:---|:---|:---|
| Frontend | 80 | 前端页面 |
| Backend | 8080 | Spring Boot API |
| FastAPI | 8000 | 预测引擎 |
| MySQL | 3306 | 数据库 |
| Redis | 6379 | 缓存 |

## 4. GPU服务器部署

### 4.1 前置要求

1. 安装 NVIDIA GPU 驱动
2. 安装 NVIDIA Docker

```bash
# 检查GPU状态
nvidia-smi

# 检查NVIDIA Docker
docker run --rm --gpus all nvidia/cuda:11.8.0-base-ubuntu22.04 nvidia-smi
```

### 4.2 修改 FastAPI Dockerfile（GPU版）

创建 `Dockerfile.gpu`:

```dockerfile
FROM nvidia/cuda:11.8.0-cudnn8-runtime-ubuntu22.04

WORKDIR /app

RUN apt-get update && apt-get install -y \
    python3.10 \
    python3-pip \
    && rm -rf /var/lib/apt/lists/*

COPY requirements.txt .
RUN pip3 install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### 4.3 修改 docker-compose.yml

```yaml
fastapi:
    build:
      context: ./synpharm-fastapi
      dockerfile: Dockerfile.gpu
    container_name: synpharm-fastapi
    ports:
      - "8000:8000"
    environment:
      DEVICE: cuda:0
      BATCH_SIZE: 50
    volumes:
      - ./synpharm-fastapi/models:/app/models
      - ./synpharm-fastapi/logs:/app/logs
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: 1
              capabilities: [gpu]
    networks:
      - synpharm-network
```

### 4.4 启动GPU服务

```bash
docker-compose up -d fastapi

# 验证GPU是否可用
docker-compose exec fastapi python -c "import torch; print('GPU available:', torch.cuda.is_available())"
```

## 5. 数据库初始化

### 5.1 创建数据库

```sql
CREATE DATABASE IF NOT EXISTS synpharm DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'synpharm'@'%' IDENTIFIED BY 'synpharm_pass';
GRANT ALL PRIVILEGES ON synpharm.* TO 'synpharm'@'%';
FLUSH PRIVILEGES;
```

### 5.2 初始化脚本

将 `synpharm-backend/src/main/resources/sql/init.sql` 导入数据库:

```bash
mysql -u synpharm -p synpharm < synpharm-backend/src/main/resources/sql/init.sql
```

## 6. 配置说明

### 6.1 后端配置 (`application.yml`)

```yaml
server:
  port: 8080

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/synpharm?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: synpharm
    password: synpharm_pass
  
  data:
    redis:
      host: localhost
      port: 6379

jwt:
  secret: your-secret-key-here
  expiration: 86400000

logging:
  level:
    com.synpharm: DEBUG
```

### 6.2 FastAPI 配置 (`.env`)

```bash
MODEL_DIR=models/
DEVICE=cuda:0
BATCH_SIZE=50
API_KEYS=["your-api-key"]
LOG_LEVEL=INFO
REQUEST_TIMEOUT=120
MAX_BATCH_SIZE=1000
```

### 6.3 前端配置 (`.env`)

```bash
VITE_APP_TITLE=SynPharm
VITE_API_BASE_URL=http://localhost:8080
VITE_API_TIMEOUT=30000
VITE_ENABLE_MOCK=false
```

## 7. 常见问题

### Q1: MySQL连接失败

确保MySQL服务已启动，并且允许远程访问:

```sql
ALTER USER 'synpharm'@'%' IDENTIFIED WITH mysql_native_password BY 'synpharm_pass';
FLUSH PRIVILEGES;
```

### Q2: Redis连接失败

检查Redis是否绑定到正确的地址:

```bash
# 修改redis.conf
bind 0.0.0.0
protected-mode no
```

### Q3: FastAPI无法识别GPU

确保已安装NVIDIA Docker，并且容器已正确配置GPU资源。

### Q4: 前端请求跨域

开发环境下，Vite已配置代理。生产环境通过Nginx反向代理解决。

### Q5: API Key认证失败

在FastAPI的 `.env` 文件中配置 `API_KEYS`，或留空禁用认证:

```bash
API_KEYS=[]
```
