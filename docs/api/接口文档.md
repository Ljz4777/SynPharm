# SynPharm 接口文档（API Contract）

> 版本：v1.0
> 更新日期：2026-08-07
> 说明：本文档描述 SynPharm 前后端 + 后端与 FastAPI 算法引擎之间的 HTTP 接口契约，与当前代码实现对齐。
> 在线文档（开发环境）：后端 `http://localhost:8080/doc.html`（Knife4j）、FastAPI `http://localhost:8000/docs`

---

## 1. 通用说明

### 1.1 Base URL

| 环境 | 地址 |
|---|---|
| 本地后端 | `http://localhost:8080` |
| Docker（生产） | 同源 `https://<域名>`，经 nginx 反代 `/api/*` |
| FastAPI 算法引擎 | `http://localhost:8000`（内网，不直接对外） |

### 1.2 认证方式

除公开接口外，请求头需携带 JWT Token：

```
Authorization: Bearer <accessToken>
```

### 1.3 统一响应格式

所有后端接口返回统一结构：

```json
{
  "code": 200,
  "message": "成功",
  "data": { }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | int | 业务状态码（见错误码表） |
| `message` | string | 提示信息 |
| `data` | object/null | 业务数据 |

### 1.4 错误码

| code | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未授权 / 未登录 |
| 403 | 禁止访问 |
| 404 | 资源不存在 |
| 500 | 系统错误 |
| 1001~1005 | 用户不存在 / 已存在 / 密码错误 / 邮箱未验证 / 已禁用 |
| 2001~2003 | Token 已过期 / 无效 / 签名无效 |
| 3001~3002 | 验证码错误或过期 / 发送太频繁 |
| 4001~4003 | 任务不存在 / 运行中 / 已完成 |
| 5001 | 结果不存在 |
| 6001 | 预测失败 |

## 2. 认证接口

### 2.1 发送验证码

- **POST** `/api/auth/captcha/send`（公开）

请求体：

```json
{
  "email": "12345678@qq.com",
  "type": "register"
}
```

| 字段 | 说明 |
|---|---|
| `email` | QQ 邮箱（5-20 位字母数字 + @qq.com） |
| `type` | `login` / `register` / `reset` |

响应 `data`：

```json
{
  "devMode": true,
  "code": "123456"
}
```

| 字段 | 说明 |
|---|---|
| `devMode` | 开发模式（`CAPTCHA_DEV_MODE=true` 且未发邮件时）为 `true`，此时验证码直接返回 |
| `code` | 仅开发模式返回验证码；生产为 `null`（验证码走邮件） |

### 2.2 注册

- **POST** `/api/auth/register`（公开）

请求体：

```json
{
  "email": "12345678@qq.com",
  "nickname": "张三",
  "password": "Abcd1234",
  "captcha": "123456"
}
```

| 字段 | 校验 |
|---|---|
| `email` | QQ 邮箱格式 |
| `nickname` | 2-20 位中文/字母/数字/下划线 |
| `password` | 8-64 位，含大小写字母和数字 |
| `captcha` | 6 位数字（type=register 验证码） |

响应 `data` = 登录响应（见 2.3），注册成功自动登录。

### 2.3 登录

- **POST** `/api/auth/login`（公开）

请求体（按 `loginType` 不同字段）：

```json
{ "loginType": "qq_email", "email": "12345678@qq.com", "captcha": "123456" }
```

```json
{ "loginType": "password", "email": "12345678@qq.com", "password": "Abcd1234" }
```

```json
{ "loginType": "guest" }
```

| loginType | 说明 |
|---|---|
| `qq_email` | 邮箱验证码登录（新用户自动注册） |
| `password` | 邮箱 + 密码登录 |
| `guest` | 游客登录（免验证码） |

响应 `data`：

```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
  "tokenType": "Bearer",
  "expiresIn": 86400,
  "isNewUser": false,
  "user": {
    "id": 1,
    "email": "12345678@qq.com",
    "nickname": "张三",
    "avatarUrl": null,
    "role": "user",
    "status": 1,
    "registerType": "qq_email"
  }
}
```

> ⚠️ Token 字段名是 **`accessToken`**（前端需读取此字段）。

### 2.4 忘记密码（重置密码）

- **POST** `/api/auth/password/reset`（公开）

请求体：

```json
{ "email": "12345678@qq.com", "captcha": "123456", "newPassword": "Newpass123" }
```

### 2.5 登出

- **POST** `/api/auth/logout`（需登录）

将当前 Token 加入黑名单，立即失效。

## 3. 用户接口（需登录）

### 3.1 获取用户信息

- **GET** `/api/users/profile`

响应 `data` = UserResponse（同 2.3 的 `user` 结构）。

### 3.2 更新用户信息

- **PUT** `/api/users/profile`

请求体（部分字段可选）：

```json
{ "nickname": "新昵称", "avatarUrl": "https://..." }
```

### 3.3 修改密码

- **PUT** `/api/users/password?oldPassword=xxx&newPassword=xxx`

### 3.4 删除账号

- **DELETE** `/api/users/account?password=xxx`

## 4. 预测接口（需登录）

### 4.1 DTI 预测

- **POST** `/api/predict/dti`

```json
{ "smiles": "CC(=O)OC1=CC=CC=C1C(=O)O", "targetId": "P00533" }
```

### 4.2 PPI 预测

- **POST** `/api/predict/ppi`

```json
{ "proteinA": "MGLGLG", "proteinB": "MVHLTE" }
```

### 4.3 DDI 预测

- **POST** `/api/predict/ddi`

```json
{ "drugASmiles": "CC(=O)OC1=CC=CC=C1C(=O)O", "drugBSmiles": "C1CCCCC1" }
```

### 4.4 预测响应结构（共用）

预测接口返回 `data` = PredictResultResponse：

```json
{
  "id": 1,
  "algoType": "DTI",
  "targetId": "P00533",
  "targetName": "EGFR",
  "ligandSmiles": "CC(=O)OC1=CC=CC=C1C(=O)O",
  "bindingAffinity": -8.5,
  "confidenceScore": 0.87,
  "confidenceLevel": "high",
  "interactions": [
    { "type": "hydrogen_bond", "residueName": "ASP", "residueNumber": null, "distance": 2.8 }
  ],
  "createdAt": "2026-08-07T10:00:00",
  "datasetInfo": {
    "name": "DTI预测结果",
    "size": 0,
    "description": "由 FastAPI 算法引擎计算",
    "source": "fastapi"
  }
}
```

> 每次预测会自动落库（生成任务 + 结果记录），供历史/结果查询使用。

### 4.5 预测历史

- **GET** `/api/predict/history`

返回当前用户历史预测列表（PredictResultResponse 数组，按创建倒序）。

## 6. 任务接口（需登录）

### 6.1 任务列表

- **GET** `/api/tasks`

返回当前用户任务列表（PredictTask，按创建倒序）。

### 6.2 任务详情

- **GET** `/api/tasks/{id}`

### 6.3 取消任务

- **DELETE** `/api/tasks/{id}`

任务对象关键字段：

```json
{
  "id": 1,
  "taskNo": "T1784000000000123",
  "userId": 1,
  "predictType": "dti",
  "inputType": "smiles",
  "inputValue": "CC(=O)OC...,P00533",
  "status": "completed",
  "progress": 100
}
```

| `status` | 说明 |
|---|---|
| pending / running / completed / failed / cancelled | 待处理 / 处理中 / 已完成 / 失败 / 已取消 |

## 7. 批量接口（需登录）

> 批量处理基于 **RabbitMQ 消息队列**实现（v3.1.0）：上传即落库并投递消息，消费者异步执行，失败进入死信队列；任务状态以 `batch_task` 表为权威。前端上传后轮询 `/status` 获取进度。

### 7.1 批量上传

- **POST** `/api/batch/upload`（multipart/form-data）

参数：

| 字段 | 说明 |
|---|---|
| `file` | CSV 文件 |
| `algoType` | `DTI` / `PPI` / `DDI` |

响应 `data`：

```json
{ "batchId": "uuid", "totalCount": 500, "status": "PENDING" }
```

### 7.2 查询进度

- **GET** `/api/batch/status/{batchId}`

响应 `data`：

```json
{
  "batchId": "uuid",
  "algoType": "DTI",
  "totalCount": 500,
  "successCount": 300,
  "failCount": 0,
  "progress": 60.0,
  "status": "PROCESSING",
  "resultUrl": "/api/batch/download/uuid",
  "createTime": "...",
  "updateTime": "..."
}
```

| `status` | 说明 |
|---|---|
| PENDING / PROCESSING / SUCCESS / FAIL | 待处理 / 处理中 / 成功 / 失败 |

### 7.3 下载结果

- **GET** `/api/batch/download/{batchId}` → 返回 CSV 文件

## 8. FastAPI 算法引擎接口（内网，X-API-Key 认证）

> FastAPI 供 SpringBoot 后端内网调用。请求头携带 `X-API-Key`（配置 `FASTAPI_API_KEYS` 后生效）；未配置则跳过校验。

### 8.1 健康检查

- **GET** `/health/`（公开）

```json
{ "status": "healthy", "service": "SynPharm AI Prediction Engine" }
```

### 8.2 单条预测

- **POST** `/v1/predict/single`

请求体（snake_case）：

```json
{ "algo_type": "DTI", "drug_smiles": "CC(=O)OC1=CC=CC=C1C(=O)O", "target_seq": "MGLGLG" }
```

| 字段 | 说明 |
|---|---|
| `algo_type` | DTI / PPI / DDI |
| `drug_smiles` + `target_seq` | DTI 用 |
| `protein_a` + `protein_b` | PPI 用 |
| `drug_a` + `drug_b` | DDI 用 |

响应：

```json
{
  "status": "success",
  "metrics": {
    "target_id": "P00533",
    "target_name": "EGFR",
    "binding_affinity": -8.5,
    "confidence_score": 0.87,
    "confidence_level": "high",
    "interactions": [ { "residue": "ASP", "type": "hydrogen_bond", "distance": 2.8 } ]
  }
}
```

> 未配置模型文件时返回 mock 结果（`_generate_mock_result`），仅用于联调，**上线前必须放入真实模型**。

### 8.3 批量预测

- **POST** `/v1/predict/batch`

请求体：

```json
{
  "algo_type": "DTI",
  "data_list": [
    { "algo_type": "DTI", "drug_smiles": "CCO", "target_seq": "MGL" },
    { "algo_type": "DTI", "drug_smiles": "C1CCCCC1", "target_seq": "MVL" }
  ]
}
```

响应：

```json
{ "status": "success", "total": 2, "results": [ { "target_id": "...", "confidence_score": 0.9, "..." : "..." } ] }
```

## 附录：常见错误响应示例

**未登录访问受保护接口**（HTTP 401）：

```json
{ "code": 401, "message": "未登录或登录已失效" }
```

**参数校验失败**（HTTP 400）：

```json
{ "code": 400, "message": "参数校验失败", "data": { "email": "请输入正确的QQ邮箱" } }
```

**Token 过期**（业务 code 2001，HTTP 200）：

```json
{ "code": 2001, "message": "Token已过期", "data": null }
```

> 前端对 `401 / 2001 / 2002 / 2003` 统一执行登出并跳转登录页。
