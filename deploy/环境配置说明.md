# SynPharm 环境配置说明

本文档讲解 SynPharm 的**容器化环境配置**：目录结构、环境变量（`.env`）、一键启动、常用命令与排障。
Dockerfile 跟随各服务源码，编排与配置统一在 `deploy/` 目录管理。

## 目录结构

```
deploy/
├── docker-compose.yml     # 服务编排入口（MySQL + Redis + 后端 + FastAPI + 前端）
├── .env.example           # 环境变量模板（复制为 .env 使用）
├── scripts/
│   ├── start.bat / .sh    # 一键启动（Windows / Linux / macOS / WSL）
│   └── stop.bat / .sh     # 一键停止
└── README.md              # 本说明
```

## 快速开始（组员）

### 前置条件

- 安装 **Docker**（Windows 用 Docker Desktop 或 WSL 中的 Docker Engine；Linux/macOS 直接安装 Docker）
- Docker 守护进程处于运行状态

### 第 1 步：进入 deploy 目录

```bash
cd deploy
```

### 第 2 步：创建并配置环境变量

```bash
# Windows
copy .env.example .env

# Linux / macOS / WSL
cp .env.example .env
```

**必须修改** `.env` 中的以下值（安全关键）：

| 变量 | 说明 |
|---|---|
| `MYSQL_ROOT_PASSWORD` / `MYSQL_PASSWORD` | 数据库密码，改成自己的强密码 |
| `JWT_SECRET` | JWT 签名密钥，至少 32 字节随机串（`openssl rand -hex 32`） |

### 环境变量详解

`.env` 中的全部可配置项（与 `deploy/.env.example` 一一对应）：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `SYNPHARM_VERSION` | 1.0.0 | 镜像标签版本 |
| `MYSQL_ROOT_PASSWORD` | - | **必填**，MySQL root 密码 |
| `MYSQL_DATABASE` | synpharm | 数据库名 |
| `MYSQL_USER` | synpharm | 应用数据库账号 |
| `MYSQL_PASSWORD` | - | **必填**，应用账号密码 |
| `MYSQL_PORT` | 3306 | 宿主机 MySQL 端口 |
| `REDIS_PORT` | 6379 | 宿主机 Redis 端口 |
| `REDIS_PASSWORD` | 空 | Redis 密码（生产建议设置） |
| `JWT_SECRET` | - | **必填**，JWT 签名密钥（≥32 字节） |
| `JWT_EXPIRATION` | 86400000 | Token 有效期（毫秒） |
| `FASTAPI_PORT` | 8000 | 宿主机 FastAPI 端口 |
| `FASTAPI_DEVICE` | cpu | 推理设备：cpu / cuda:0 |
| `FASTAPI_BATCH_SIZE` | 50 | 批量推理大小 |
| `FASTAPI_API_KEY` | 空 | 后端调用算法引擎的单一 Key（开启认证必填） |
| `FASTAPI_API_KEYS` | 空 | FastAPI 接受的全部 Key（逗号分隔，可多个） |
| `FASTAPI_LOG_LEVEL` | INFO | 日志级别 |
| `BACKEND_PORT` | 8080 | 宿主机后端端口 |
| `FRONTEND_PORT` | 80 | 宿主机前端端口 |
| `QQ_EMAIL` | 空 | 验证码发件邮箱 |
| `QQ_EMAIL_AUTH_CODE` | 空 | 邮箱授权码 |

> 修改 `.env` 后需重启服务生效：`docker compose up -d`

### 第 3 步：一键启动

```bash
# Windows
scripts\start.bat

# Linux / macOS / WSL
./scripts/start.sh
```

首次启动会自动构建镜像（需联网，后端/FastAPI 首次构建约 10~30 分钟），之后秒级启动。

### 第 4 步：访问

| 服务 | 地址 |
|---|---|
| 前端页面 | http://localhost （默认端口 80，可在 `.env` 改 `FRONTEND_PORT`） |
| SpringBoot 文档 | http://localhost:8080/doc.html |
| FastAPI 文档 | http://localhost:8000/docs |
| 健康检查 | http://localhost:8080/actuator/health |

## 常用命令

```bash
# 查看所有服务状态
docker compose ps

# 查看日志（实时）
docker compose logs -f

# 查看某个服务日志
docker compose logs -f backend
docker compose logs -f fastapi

# 停止服务（保留数据）
scripts\stop.bat        # 或 ./scripts/stop.sh

# 彻底清理（删除所有数据卷，慎用）
docker compose down -v
```

## 常见问题

**Q：MySQL 起不来，端口被占用？**
改 `.env` 中 `MYSQL_PORT` 后重启。

**Q：后端一直 unhealthy？**
```bash
docker compose logs backend   # 查看报错
```
常见原因：数据库密码与 `.env` 不一致、JWT_SECRET 太短、Redis 连不上。

**Q：FastAPI 一直 unhealthy？**
```bash
docker compose logs fastapi
```
首次启动需安装 torch 依赖，耐心等待；也可先确认 `models/` 目录存在（可为空）。

**Q：前端页面打不开？**
确认 `FRONTEND_PORT` 未被占用，且后端已 healthy。

## 安全提醒

- `.env` 已加入 `.gitignore`，**不要提交到版本库**
- 生产环境务必：设置强密码/密钥、开启 FastAPI 的 `FASTAPI_API_KEYS`、限制数据库端口不对外暴露
